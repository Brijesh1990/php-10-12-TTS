# what is file handeling in php ?
 
   1. file handeling is used to handel file in php
   2. file handeling is used to how to open file | close file | read file | write file | read write | get files | removed files etc 
   3. file handeling provides some function ... 

        1. fopen()
        2. fclose()
        3. fgets()
        4. fwrite()
        6. fread()
        7. unlink()


    4. file handeling used some mode to read|write on file 

       1. r => read only
       2. r+ => read | write only
       3. w => write only but if file is not available create new file
       4. w+ =>read and write if file is now available create new file
       5. a => append on file
       6. a+ =>append on file and create new if file is not available
