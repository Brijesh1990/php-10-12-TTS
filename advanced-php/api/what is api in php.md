# what is api in php ?

  1. api stands for application programming interface 
  2. api is used to take response from server 
  3. api create from web apps | mobiles apps | ios apps 
  4. api data pass on server in form of json 
  5. api data take response from server always in json data
  6. api create for any crud apps 

     **api crud app**
     1. create api
     2. read api 
     3. update api
     4. delete api 
     5. product add api 
     6. image upload api 
     7. login and register api 
# what is json ?  

  1. json stands for javascript object notations 
  2. json get data in objects 
  3. json stored multiple objects data using array 
  4. json file extension .json
  5. php will used to encode and decode json formate 

    **php used json_encode() and json_decode() data**
    1. json_encode()
    2. json_decode()
